# Load smoke, 2026-11-16 (T-116)

Script: `tests/load/smoke.js` (k6 2.3.0).
- **Accounts:** 50 verified accounts from `tests/load/create-users.mjs`, each signed in and reset (P11) per run.
- **Trading VUs:** 50, one per account. Each does one NVDA proposal and five assessments, then sends the same order twice at once with one Idempotency-Key.
- **Readers:** 50 more VUs on `/portfolio`, `/signals` and `/portfolio/positions` for 60 s.

Environment: the compose stack on Docker Desktop (macOS, Apple Silicon), with the API at Information logging (`LOG_LEVEL=Information`), auth limits raised for the run (`AUTH_PER_MINUTE`, `AUTH_PER_HOUR`), OTel export on, and the iOS simulator running. About 30 requests/s.

| Measure | Target | Run A | Run B (all 50 traders active) |
|---|---|---|---|
| Orders p95 (NFR-02) | ≤ 500 ms | 344 ms | 406 ms ✓ |
| Reads p95 (NFR-01) | ≤ 300 ms | 279 ms | **382 ms** ✗ |
| Assessments p95 (held to NFR-01) | ≤ 300 ms | 191 ms | **481 ms** ✗ |
| Duplicate fills | 0 | 0 | 0 ✓ (50/50 accounts: one 64-share position, cash 88,056.32) |
| Checks | 100 % | 90 %* | 100 % |

\* Run A's five failures were a script bug: trading VUs got VU ids past the token list. It was fixed before Run B.

Per endpoint (Run A): portfolio 228 ms, positions 257 ms, signals list 352 ms.

## Verdict

- **Order path:** meets NFR-02, and the duplicate-fill guarantee holds under concurrency.
- **Reads and assessments:** over 300 ms on this machine with everything running. T-116 stays open: re-run on staging (T-117), or profile the signals list and portfolio valuation (likely candidates: the per-request quote and instrument lookups).

## Run it

```
node tests/load/create-users.mjs                    # once
LOG_LEVEL=Information AUTH_PER_MINUTE=100000 AUTH_PER_HOUR=1000000 pnpm stack:up
docker run --rm -i --network astryx_default --add-host host.docker.internal:host-gateway \
  -e API_URL=http://host.docker.internal:5080 -v "$PWD/tests/load:/load" grafana/k6:2.3.0 run /load/smoke.js
pnpm stack:up                                        # back to the default limits and log level
```
